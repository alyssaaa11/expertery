# Example past work: 20 mounting brackets

Each folder is one finished past job, the way a company would hand it over: `request.txt` (what the employee
asked for) and `part.py` (the finished CadQuery part; it defines `result`). Made from experiments/brackets/jobs_brackets.jsonl
(2026-11-03). Known wording problems found by reading failed answers: B2 ("80 long") and B16 (sides' start height),
noted in results/brackets-2026-11-03/REPORT.md. Use: `expertery exam build examples/past-work-brackets --out <dir>`.
