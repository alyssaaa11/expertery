# Expertery live demo (built and launched 2026-11-02)

**Summary**: The product page is live at **https://expertery.vercel.app**. A visitor describes a part; the
trained Glimmer (r5f) writes CadQuery, a locked Modal box builds it, the model checks its own measurements and fixes
(≤ 3 rounds, the FTX loop of the 92% second look), and the page shows a 3D view, measurements, code and STEP/STL.
Built by Muse Code in 4 rounds from Claude's spec, with small disclosed Claude fixes; reviewed by the verifier.

## What is live (verified 2026-11-02 ~22:45-23:10)
- **Public page:** Vercel project `homegrown-factory` → https://expertery.vercel.app (public, no login; checked
  with curl 200 and a headless Chrome visit: counter shown, no CORS errors).
- **Engine:** Modal app `homegrown-web` (CPU, max 1 container) and model app `forge-trained` (r5f merged, A100,
  sleeps after 5 min). Their URLs contain the Modal workspace name, so they are kept out of the repo (decision, user:
  "I don't like putting modal and my personal gmail"); find them with `modal app list`.
- **Why the page calls the engine directly (CORS) and not through a Vercel proxy:** a proxy makes every visitor look
  like one IP, so the 1-try limit would block everyone after the first visitor. `ALLOWED_ORIGINS` is baked at deploy.
- **Settings (startup log `homegrown-web config`, verified):** TOTAL_CAP_USD 15, DAILY_CAP_USD 15 (= no separate daily
  cap), MAX_LIVE_TRIES_PER_VISITOR 1, EST_TRY_USD 0.60, REASONING_STRENGTH xhigh, 600 chars, 2 concurrent, build limit
  600 s, warm-up throttle 10 min global / 1 h per IP.
- **Form leads:** stored only in Modal Dict `homegrown-leads` (no email/Slack); Claude reads them on request. Delete by
  sending the form again with the word "delete".

## First real live build (verified, live_run.sse, 2026-11-02 ~22:40)
- L-bracket 80 × 30 × 5 base + 40 mm wall + two 6 mm holes → **Self-check PASS**, bbox 80 × 30 × 45, 1 solid, volume
  27,717.257 mm³ = 12,000 + 16,000 − 2·π·3²·5 (exact). 120 s total, 106 s model time, **3 rounds**.
- It is now the page's recorded demo (`app/web/recorded_run.json`, file URLs removed because files expire in 24 h).
- **Cold start of the model took ~14 min** (825 s until vLLM "Application startup complete"). Wake it before
  recording the video or a judging slot.
- **The trained model never says DONE**: it resubmits the same code after each self-check, so every live try uses all
  3 rounds (≈ 3× the GPU of one answer). hypothesis: r5f was trained on single-turn answers only (verifier F2 predicted
  this). Possible fix (not done): end the loop when the code is unchanged.
